The system will be a plugin loader (referred to as "libs"). There will be a folder within the compiler called "lib loader"—accompanied by a warning regarding the risk of viruses from libs provided by unknown sources—and the lib loader will add extra functions to the language.

commands for installing libs: "inst hmx --author; package name"

If you want complete security and are worried about downloading libraries containing viruses, only download using the command "inst hmx --monolithiiun; package name".
